# Composition через явный prop вместо children

Composition — это не обязательно про `children`. Иногда удобнее передать JSX через обычный именованный prop, особенно если слотов несколько.

```jsx
function App() {
  return (
    <Card icon={<span>💎</span>} title={<h2>Premium план</h2>} footer={<button>Оформить</button>} />
  );
}

function Card({ icon, title, footer }) {
  return (
    <div className="card">
      <div className="card-icon">{icon}</div>
      {title}
      <div className="card-footer">{footer}</div>
    </div>
  );
}
```

## Что здесь происходит

`Card` не принимает `children`. Вместо одного универсального слота у неё три именованных: `icon`, `title`, `footer`. Каждый — это просто prop, в который снаружи, в `App`, кладётся готовый кусок JSX. Внутри `Card` эти пропсы просто вставляются в нужные места разметки — точно так же, как вставлялся бы `children`, только их несколько и каждый на своём месте.

Технически разницы с `children` нет: React и в том, и в другом случае получает JSX-элемент как значение prop и рендерит его. Разница только в том, что `children` — это встроенное, автоматическое имя для контента между тегами, а `icon`/`title`/`footer` — обычные пропсы, которые нужно передавать явно через `component={...}` и придумывать им имена самому.

## Когда children достаточно, а когда нужен явный prop

Одного слота хватает почти всегда — это стандартный, идиоматичный способ в React:

```jsx
<Card>
  <h2>Premium план</h2>
</Card>
```

Явный именованный prop нужен, когда в компонент нужно положить несколько независимых кусков контента, которые должны попасть в разные места разметки, и компоненту важно их различать:

```jsx
function Layout({ sidebar, content }) {
  return (
    <div className="layout">
      <aside>{sidebar}</aside>
      <main>{content}</main>
    </div>
  );
}

<Layout sidebar={<Menu />} content={<Dashboard />} />;
```

Здесь `children` не подошёл бы напрямую — непонятно было бы, что из переданного контента должно уйти в `<aside>`, а что в `<main>`. Именованные пропсы решают эту неоднозначность.

## Итог

Оба подхода — это composition: компонент не знает заранее, что внутри него, и получает содержимое снаружи. `children` — вариант по умолчанию для одного слота, явные пропсы — вариант для нескольких слотов с понятными ролями. Такой паттерн встречается, например, в React Router.
