# Component Composition

Учимся комбинировать компоненты через children, чтобы разорвать жёсткую связь между ними и сделать их по-настоящему переиспользуемыми.

```jsx
// ❌ Без композиции — Success жёстко "зашит" внутрь Modal
function Modal() {
  return (
    <div className="modal">
      <Success />
    </div>
  );
}

// ✅ С композицией — Modal принимает children
function Modal({ children }) {
  return (
    <div className="modal">
      {children}
    </div>
  );
}

// Теперь можно передавать что угодно
<Modal>
  <Success />
</Modal>

<Modal>
  <Error />
</Modal>
```

В первом варианте `Success` реально находится внутри `Modal` — они жёстко связаны прямо в JSX. Из-за этого `Modal` больше нельзя переиспользовать для чего-то другого — по сути это уже не "модалка", а "модалка успеха", потому что она умеет показывать только `Success`.

Во втором варианте `Modal` не содержит заранее заданный компонент, а просто принимает `children`. `Success` передаётся снаружи — между открывающим и закрывающим тегом `Modal`. Это оставляет внутри компонента как бы пустой слот, который можно заполнить чем угодно: `Success`, `Error`, любым другим компонентом.

Формально композиция — это техника комбинирования разных компонентов через `children` или через явную передачу компонентов как пропсов. Работает это именно потому, что компонент заранее не знает, что будет внутри него — он просто резервирует место.

Используется в двух ситуациях:

Первая — когда нужно сделать компонент гибким и переиспользуемым, как в примере с модалкой. Это происходит постоянно в реальных проектах.

Вторая — чтобы решить проблему prop drilling (передачи пропсов через много промежуточных уровней компонентов, которым они сами не нужны). Это же особенно полезно при построении layout'ов — общих "рамок" страницы, куда подставляется разный контент.
