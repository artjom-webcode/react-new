# Children Prop

Учимся передавать контент внутрь компонента через children — так же, как обычный div может содержать что угодно внутри себя.

```jsx
export default function App() {
  return (
    <div className="app">
      <h1>Children Prop</h1>

      {/* Button получает JSX между тегами как children */}
      <Button>
        <span>👈</span>
        Previous
      </Button>

      <Button>
        Next
        <span>👉</span>
      </Button>
    </div>
  );
}

// Reusable Button component
function Button({ children }) {
  return <button className="button">{children}</button>;
}
```

`children` — специальный проп, который React автоматически передаёт компоненту, если между его открывающим и закрывающим тегом что-то написано. Всё, что находится внутри `Button`, React упаковывает и отдаёт компоненту как проп с именем `children`. Внутри самого компонента это просто вставляется в нужное место.

Для чего это нужно:

Переиспользуемость — один и тот же компонент `Button` используется два раза с разным содержимым внутри: один раз иконка слева от текста, другой раз справа. Стили и логика кнопки не дублируются, а меняется только то, что внутри.

Гибкость — компонент-обёртка не знает заранее, что будет внутри него: текст, иконка, другой компонент. Он просто резервирует место, куда подставится всё, что передаст вызывающий код.

Похоже на HTML-теги — это тот же паттерн, что у обычных элементов вроде `div` или `ul` с `li` внутри. `children` даёт твоим компонентам такое же поведение — способность оборачивать произвольный контент.
